## Overview

RL Playground is a compact framework for training, evaluating and visualising reinforcement learning agents on
custom [Gymnasium](https://gymnasium.farama.org) environments. Its first environment is a top-down racing task in
which a car perceives the track through nine ray-cast sensors and learns to steer, accelerate and brake from reward
alone.

- **Custom environment** with procedurally generated tracks for testing generalisation to unseen layouts
- **PPO training** via Stable-Baselines3 with parallel environments, checkpoints and TensorBoard metrics
- **Reproducible evaluation** on fixed episode sets, with summary tables and JSON export
- **Live telemetry viewer** showing sensor readings, policy outputs and reward as the agent drives

## Installation

Requires Python 3.11+ and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/xquantize/rl-playground.git
cd rl-playground
uv sync
```

## Usage

```bash
uv run rlp train --name baseline                      # train on the default track
uv run rlp train --name generalist --track random     # train on a new random track each episode
uv run rlp watch runs/baseline                        # watch an agent with live telemetry
uv run rlp compare runs/baseline runs/generalist      # race agents against each other
uv run rlp evaluate runs/baseline --track random      # score an agent on unseen tracks
uv run rlp drive                                      # drive the car yourself
```

Models can be referenced by run directory or by checkpoint, for example
`runs/baseline/checkpoints/model_200000_steps.zip`. Visual commands accept `--record <path>.gif`, optionally with
`--headless` to render without a window. Run `uv run rlp <command> --help` for all options.

Training metrics, including lap count and crash rate, are logged to TensorBoard:

```bash
uv run tensorboard --logdir runs
```

## Environment

The racing environment is registered as `rl_playground/Racing-v0`.

```python
import gymnasium as gym
import rl_playground.envs

env = gym.make("rl_playground/Racing-v0", track_mode="random", render_mode="human")
```

| Component | Specification |
| :-- | :-- |
| Observation | 12 values: nine sensor distances across a 180° field of view, speed, and the heading relative to the track |
| Action | Steering and throttle, each in [-1, 1]; negative throttle brakes |
| Reward | +100 per lap of progress, −0.01 per step, −10 for leaving the track |
| Termination | Leaving the track |
| Truncation | 1,500 steps, or 150 consecutive steps without progress |

The car cannot turn while stationary and cannot hold the tightest corners at full speed, so a competent policy must
learn to brake into turns. Random tracks are generated by perturbing a circle with low-frequency harmonics, rejecting
any layout whose corners are too tight for the track width.
